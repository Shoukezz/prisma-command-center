# PRISMA

## Vision

PRISMA is a browser-based strategic command center simulator.

The player acts as the Director of a multinational intelligence and operations center.

The player never directly controls military units.

The player controls:

- intelligence gathering
- analysts
- strategic assets
- operations
- diplomacy

The game focuses on uncertainty.

The player never sees the true state of the world.

All information is filtered through intelligence systems.

The core fantasy is:

"I am running a real strategic command center."

The game should feel realistic, tense and information-driven.

No arcade mechanics.

No RTS gameplay.

No direct unit control.

Decisions create consequences.

Information is the primary resource.
