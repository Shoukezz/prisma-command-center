# Core Systems

## Intelligence

Sources:

- SATINT
- SIGINT
- HUMINT
- CYBER

Every report has:

- confidence score
- timestamp
- source

Players never know if information is fully accurate.

---

## Operations

Types:

- Recon
- Strike
- Cyber
- Special Operation
- Influence Operation

Operations consume resources.

Operations take time.

Operations can fail.

---

## Assets

Examples:

- satellites
- drone wings
- agents
- cyber teams

Assets can:

- become unavailable
- be damaged
- be destroyed

---

## Analysts

Analysts interpret information.

Different analysts have different biases.

Analysts can be wrong.

---

## Diplomacy

Countries react to events.

Relationships constantly change.

The player must manage political consequences.

---

## Event Engine

The world continuously generates events.

Examples:

- border conflict
- cyber attack
- coup
- terrorist incident
- economic crisis
